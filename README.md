# Code Card Studio

أداة ويب مجانية وخفيفة لتحويل الأكواد البرمجية إلى بطاقات بصرية عالية الدقة جاهزة للنشر.

## المميزات
- تلوين تلقائي لصياغة الكود (Python, JavaScript, SQL وغيرها).
- مقاسات جاهزة لمنشورات التواصل الاجتماعي (1080x1080 و1080x1350 أو تلقائي).
- 5 ثيمات لونية احترافية مع إمكانية إضافة علامة مائية ورقم الأسطر.
- تعمل بالكامل داخل المتصفح دون الحاجة لخادم أو إنترنت.
