# Code Card Studio

أداة ويب مجانية وخفيفة لتحويل الأكواد البرمجية إلى بطاقات بصرية عالية الدقة جاهزة للنشر.

## المميزات (v2.1)
- تلوين تلقائي لصياغة الكود مع تمييز الدوال والتعليقات وأمثلة جاهزة (Python, JavaScript, SQL).
- أنماط خلفية (تدرج لوني، شبكة، نقاط) واستدارة حواف قابلة للتخصيص.
- مقاسات جاهزة لمنشورات التواصل الاجتماعي (1080x1080 و1080x1350 أو تلقائي).
- تصدير بصيغة PNG وJPEG مع نسخ الكود أو الصورة وحفظ الإعدادات محلياً.
